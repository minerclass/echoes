# Echoes v1: Five worlds of the word

The earlier version of this game, kept as the fallback for browsers without WebGL. The main game links here when the 3D renderer cannot start or loses its graphics context.

It covers the same five media environments as the current version, drawn with a 2D canvas instead of WebGL, and it works as a standalone page. Movement is WASD with arrow keys or dragging to turn; Space or a click pulses the node you are aiming at; a guided mode reaches the same ending without navigation.

This is a superseded build. It is kept because a fallback that does not work is worse than no fallback, and it is not maintained alongside the current game. Read the top-level `README.md` for what the project is and what it claims, and `validation.md` for what has been tested. Neither of those documents covers this folder.
